## Retrieval readiness

These are source acquisitions, not approved answer cards. The current app uses nonrecursive source-folder scans; this nested incoming folder has not been added to its index. No live index or answer behavior was changed.

Preparation means extracting complete procedural units with prerequisites, supplies, quantities, timing, warnings, age groups, scope, edition and page references attached. Tables and diagrams need checks against the originals. Conflicting older instructions need explicit precedence or exclusion. Retrieval examples should then confirm that a question gets the right complete unit.

For example, a canning processing time must travel with the food, preparation method, jar size, pressure or temperature, altitude adjustment and exclusions. Being able to search a paragraph is not enough.
